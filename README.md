# 🐍 Snake Game - Python + Pygame

A classic Snake game built from scratch using **Python** and **Pygame**. This project demonstrates my skills in Object-Oriented Programming (OOP), event handling, collision detection, and game loop management.

## 🎮 Features

- Smooth snake movement with arrow keys
- Score tracking system
- Grid-based collision detection
- Food spawning with position validation (prevents overlap with snake)
- Auto-restart on collision with self
- Clean OOP structure with `Snake` and `Food` classes

## 🖥️ How to Run

1. Clone the repository:

   git clone https://github.com/mobinabyt/Snake-Game-Python.git
   cd Snake-Game-Python
   
   2.Install dependencies:
   pip install -r requirements.txt

   3.Run the game :
   python snake.py
